## Featured projects

### 🎮 [League Helper](https://github.com/alanliu2003/league-helper)
A full-stack League of Legends analytics and AI-coaching monorepo. It supports player search, match ingestion, champion statistics, playstyle analysis, and optional AI-generated insights.

**Highlights**
- Nuxt and TypeScript frontend with Tailwind CSS
- NestJS REST API with Prisma and PostgreSQL
- Redis and BullMQ workers for durable background processing
- Riot Games API integration and Data Dragon static-data enrichment
- Shared TypeScript packages, Zod validation, automated tests, and Docker-based local development

### 🛒 [GIX Purchase Tracker](https://github.com/alanliu2003/GIX_Purchase)
A team purchasing web application for submitting requests, tracking purchase statuses, and managing team budgets.

**Highlights**
- FastAPI backend and JavaScript frontend
- Streamlit interface for alternate student/coordinator workflows
- MySQL-backed purchase and budget tracking
- Docker Compose deployment for reproducible local setup

### 🦠 [Disease Spread Simulation](https://github.com/alanliu2003/Disease-Spread-Simulation)
A Python project that models disease spread through simulation.

### 🕹️ [Game Development Projects](https://github.com/alanliu2003/TECHIN512-Final-Alan-Liu)
